# Research/Modeling vs Safety-Gated Runtime Separation

## 1. Scientific Separation of Concerns
- **IMAGINA (Modeling/Research)**: Located in external repository `../Imagina`. Source of truth for model cards, notebooks, SQLite event data, Next.js dashboard, and scientific reports.
- **NeuroVerse (Safety-Gated Runtime)**: Enforces determinism, async protocol engine, structured reason codes, LSL/BrainFlow hardware readiness, LateFusionV1 logic, and closed-loop lock governance.

## 2. Intended Scientific Framing
- *"IMAGINA is an external research/modeling project. NeuroVerse is the safety-gated runtime and neuroadaptive interface layer."*
- *"IMAGINA outputs are experimental imagery proxy estimates, not decoded thoughts or dreams."*
- *"The corridor is not a decoded mental image. It is an adaptive scaffold driven by experimental proxy metrics."*
- *"Closed-loop from real EEG is disabled by default."*
